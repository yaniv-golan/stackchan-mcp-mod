# Code of Conduct

This project follows the [Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good faith, and keep discussion focused on the work. Harassment, personal attacks
and demeaning comments are not welcome here.

Report unacceptable behaviour to the maintainer through a GitHub issue if it can be public, or privately otherwise.
Reports are handled confidentially, and the maintainer may remove comments, reject contributions or block accounts
in response.
